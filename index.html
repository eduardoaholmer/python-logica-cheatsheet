01Variáveis & tipos

lógica
Uma variável é uma caixinha com nome. Você guarda um valor dentro dela pra usar depois. O tipo define o que cabe nessa caixa: número, texto, verdadeiro/falso, lista de coisas, etc.
por que usar
código mais legível evita repetir valores muda em um lugar só nome revela a intenção tipos previnem erros
Python
# criar = dar nome + valor
nome  = "Eduardo"       # str
idade = 22              # int
salto = 1.78            # float
ativo = True            # bool
frutas = ["maçã", "uva"]  # list
tipos principais
TipoO que guarda

strtexto ("olá")
boolTrue ou False

tuplecoleção ordenada e imutável

dictchave → valor

02Operadores

lógica — matemáticos
Fazem contas. O resultado vai para uma variável ou é usado direto numa condição.
por que usar
cálculos direto no código base de qualquer decisão expressões compostas em uma linha
OpFazExemplo
+adição3 + 2 → 5
-subtração3 - 2 → 1
*multiplicação3 * 2 → 6
/divisão (float)7 / 2 → 3.5
//divisão inteira7 // 2 → 3
%resto da divisão7 % 2 → 1
**potência2 ** 3 → 8
lógica — comparação
Comparam dois valores e devolvem True ou False. São a base de toda decisão.
OpPergunta que fazExemplo
==são iguais?3 == 3 → True
!=são diferentes?3 != 4 → True
>esquerda é maior?5 > 3 → True
<esquerda é menor?3 < 5 → True
>=maior ou igual?5 >= 5 → True
<=menor ou igual?3 <= 5 → True
lógica — booleanos
Combinam condições. A pergunta vira uma resposta única: verdadeiro ou falso.
# and → as DUAS precisam ser True
idade >= 18 and tem_cnh == True

# or → PELO MENOS UMA precisa ser True
eh_admin or eh_moderador

# not → inverte
not esta_logado  # True se NÃO estiver logado

03Condicionais

lógica
"Se isso for verdade, faça A. Senão, faça B." — o programa toma decisões. Pensa como uma bifurcação na estrada: dependendo da resposta, você vai por um caminho ou outro.
por que usar
controle de fluxo claro separa casos de sucesso e erro cada caminho testável isoladamente evita executar lógica indevida
fluxo mental
condição? ──→ True  → bloco if
          └──→ False → bloco else

múltiplas? → elif encadeia
cada elif é uma nova pergunta
Python
nota = 7

if nota >= 9:
    print("Excelente")
elif nota >= 6:
    print("Aprovado")
else:
    print("Reprovado")
lógica — ternário
Condicional em uma linha. Use quando a lógica é simples.
# valor_se_true if condição else valor_se_false
status = "maior" if idade >= 18 else "menor"
lógica — in
Verifica se um valor está dentro de uma coleção.
cores = ["azul", "verde", "vermelho"]

if "azul" in cores:
    print("tem azul!")

if "rosa" not in cores:
    print("sem rosa")

04Loops

lógica
Repetição controlada. Dois tipos de pergunta: "repita X vezes" (for) ou "repita enquanto for verdade" (while). A diferença é: no for você sabe quantas vezes. No while você não sabe — para quando a condição mudar.
por que usar
elimina código repetido escala para qualquer volume de dados DRY — escreva uma vez comprehension: conciso e expressivo processamento em lote
for — iterar lista
Para cada item da coleção, execute o bloco.
nomes = ["Ana", "Bruno", "Carla"]

for nome in nomes:
    print(f"Olá, {nome}!")
for — com range
Quando você precisa de um contador numérico.
for i in range(5):        # 0 a 4
    print(i)

for i in range(1, 6):    # 1 a 5
    print(i)

for i in range(10, 0, -1): # 10→1
    print(i)
for — com enumerate
Quando você precisa do índice E do valor ao mesmo tempo.
frutas = ["maçã", "uva", "pera"]

for i, fruta in enumerate(frutas):
    print(f"{i}: {fruta}")
# 0: maçã  /  1: uva  /  2: pera
while
Repete enquanto a condição for verdadeira. Cuidado: se nunca virar False, loop infinito.
contador = 0

while contador < 3:
    print(contador)
    contador += 1
# 0, 1, 2
break / continue
break = para o loop agora. continue = pula para a próxima volta.
for n in range(10):
    if n == 3:
        continue  # pula o 3
    if n == 6:
        break     # para no 6
    print(n)  # 0 1 2 4 5
list comprehension
Cria uma lista nova a partir de outra em uma linha. For + condição + resultado = lista.
nums = [1, 2, 3, 4, 5]

# dobrar todos
dobros = [n * 2 for n in nums]
# [2, 4, 6, 8, 10]

# só os pares
pares = [n for n in nums if n % 2 == 0]
# [2, 4]

05Funções

lógica
Uma função é um bloco de código com nome que você pode chamar quantas vezes quiser. Recebe dados (parâmetros), faz algo, devolve um resultado (return). Pensa como uma máquina: coloca algo na entrada, sai algo na saída.
por que usar
escreva uma vez, use em qualquer lugar testável de forma isolada bug corrigido em um único lugar nome documenta a intenção divide problemas grandes em partes pequenas
definir + chamar
def saudar(nome):
    return f"Olá, {nome}!"

resultado = saudar("Eduardo")
print(resultado)
# Olá, Eduardo!
parâmetro padrão
Valor usado quando o argumento não é passado.
def conectar(host="localhost", porta=3306):
    print(f"{host}:{porta}")

conectar()              # localhost:3306
conectar("prod.db")    # prod.db:3306
conectar(porta=5432)   # localhost:5432
múltiplos retornos
Python retorna tuplas naturalmente — desestruture direto.
def minmax(lista):
    return min(lista), max(lista)

menor, maior = minmax([3, 1, 7, 2])
# menor=1  /  maior=7
*args — n argumentos
Quando você não sabe quantos argumentos posicionais virão.
def somar(*nums):
    return sum(nums)

somar(1, 2)           # 3
somar(1, 2, 3, 4)   # 10
**kwargs — argumentos nomeados
Quando você não sabe quais argumentos com nome virão. Chegam como um dicionário.
def configurar(**opcoes):
    for k, v in opcoes.items():
        print(f"{k} = {v}")

configurar(cor="azul", tamanho=12)
# cor = azul  /  tamanho = 12
lambda — função anônima
Função de uma linha, sem nome. Útil passada como argumento para outra função.
# lambda argumentos: expressão
dobro = lambda x: x * 2
dobro(5)  # 10

# ordenar por tamanho do nome
nomes = ["Carla", "Ana", "Bruno"]
sorted(nomes, key=lambda n: len(n))
# ["Ana", "Bruno", "Carla"]

06Strings

lógica
Uma string é uma sequência de caracteres. Funciona como uma lista de letras: tem índices, pode ser fatiada, mas é imutável — você não muda a string original, cria uma nova.
por que usar
métodos prontos — sem lógica manual f-string: interpolação simples e legível imutabilidade garante segurança fatiamento flexível
criar + acessar
s = "Olá, mundo"

s[0]      # "O"
s[-1]     # "o"
s[0:3]    # "Olá"
len(s)    # 10

# f-string: interpola variáveis
nome = "Eduardo"
print(f"Olá, {nome}!")
métodos essenciais
MétodoFaz
.upper()tudo maiúsculo
.lower()tudo minúsculo
.strip()remove espaços das bordas
.split(sep)divide em lista
.join(lista)une lista em string
.replace(a, b)substitui a por b
.find(sub)posição ou -1
.startswith(s)começa com s?
.count(sub)conta ocorrências
exemplos práticos
frase = "  Python é incrível  "

frase.strip()
# "Python é incrível"

frase.replace("Python", "JS")
# "  JS é incrível  "

palavras = "a,b,c".split(",")
# ["a", "b", "c"]

"-".join(palavras)
# "a-b-c"
verificações
s = "email@exemplo.com"

"@" in s               # True
s.startswith("email") # True
s.endswith(".com")    # True
s.count("e")          # 2
s.find("@")           # 5

lógica
Uma coleção ordenada de itens. Cada item tem um índice (começa em 0). Mutável: você pode adicionar, remover, modificar.
por que usar
agrupa dados relacionados ordenação e busca embutidas fatiamento para sub-conjuntos indexação previsível 
t = ["a", "b", "c", "d"]

t[0]     # "a"  (primeiro)
t[-1]    # "d"  (último)
t[1:3]   # ["b","c"]  (slice)
len(t)   # 4

08Dicionários

lógica
Estrutura de chave → valor. Ao invés de índice numérico, você acessa pelo nome. Pensa como um perfil de usuário: usuario["nome"] devolve o nome, usuario["email"] devolve o email.
por que usar
busca por chave em O(1) dados autodocumentados ideal para configurações e perfis leitura intuitiva fácil de serializar para JSON
criar + acessar
pessoa = {
    "nome": "Eduardo",
    "idade": 22,
    "ativo": True
}

pessoa["nome"]           # "Eduardo"
pessoa["idade"]          # 22
pessoa.get("email", "—") # "—" (não existe)
iterar
# só as chaves
for chave in pessoa:
    print(chave)

# chave e valor juntos
for k, v in pessoa.items():
    print(f"{k}: {v}")

# verificar existência
"nome" in pessoa  # True
modificar
pessoa["idade"] = 23   # atualiza
pessoa["city"] = "POA"  # adiciona
del pessoa["ativo"]     # remove
dict como contador
Padrão clássico: contar ocorrências de palavras/itens.
texto = ["a", "b", "a", "c", "a"]
contagem = {}

for item in texto:
    contagem[item] = contagem.get(item, 0) + 1

# {"a": 3, "b": 1, "c": 1}
dict comprehension
Cria um dicionário em uma linha — mesma lógica do list comprehension, mas com chave: valor.
# inverter chave/valor
original = {"a": 1, "b": 2}
invertido = {v: k for k, v in original.items()}
# {1: "a", 2: "b"}

# filtrar por valor
notas = {"Ana": 9, "Bruno": 5, "Carla": 7}
aprovados = {k: v for k, v in notas.items() if v >= 6}
# {"Ana": 9, "Carla": 7}

09Tuplas & Sets

lógica
Tupla: como uma lista, mas imutável — depois de criada, não muda. Ideal para dados que não devem ser alterados (coordenadas, cores RGB, configurações). Set: coleção sem ordem e sem duplicatas — útil para checar pertencimento e operações de conjunto.
por que usar
tupla: integridade garantida set: sem duplicatas automático operações de conjunto nativas set: busca mais rápida que lista desestruturação direta
tupla
# criar com parênteses
coords = (10, 20)
rgb    = (255, 128, 0)

coords[0]   # 10
len(coords) # 2

# desestruturar
x, y = coords
print(x, y) # 10  20
set
# duplicatas removidas automaticamente
cores = {"azul", "verde", "azul"}
# {"azul", "verde"}

cores.add("vermelho")
cores.discard("verde")
"azul" in cores  # True
operações de conjunto
Sets suportam operações matemáticas de conjuntos.
a = {1, 2, 3}
b = {2, 3, 4}

a & b  # {2, 3}        — interseção
a | b  # {1, 2, 3, 4}  — união
a - b  # {1}           — diferença

10Tratamento de erros

lógica
"Tente fazer isso. Se der errado de tal jeito, faça aquilo. Acontecendo erro ou não, sempre faça isso no fim." — evita que o programa quebre e te dá controle sobre o que pode falhar.
por que usar
programa resiliente a falhas mensagens claras para o usuário lógica separada do tratamento de erros finally garante limpeza de recursos raise sinaliza regras de negócio
estrutura
try:
    resultado = 10 / x
except ZeroDivisionError as e:
    print(f"Erro: {e}")
except TypeError:
    print("Tipo errado!")
else:
    print("Deu certo!", resultado)
finally:
    print("Sempre roda")
o que cada bloco faz
BlocoQuando roda
trycódigo que pode falhar
exceptse o erro especificado ocorrer
elsese NÃO deu erro
finallysempre, com ou sem erro
erros comuns
ErroCausa
TypeErrortipo errado de dado
ValueErrorvalor inválido
KeyErrorchave não existe no dict
IndexErroríndice fora da lista
ZeroDivisionErrordivisão por zero
FileNotFoundErrorarquivo não existe
raise — lançar erro
Você mesmo pode lançar um erro quando uma regra de negócio falha.
def sacar(saldo, valor):
    if valor > saldo:
        raise ValueError("Saldo insuficiente")
    return saldo - valor

try:
    sacar(100, 200)
except ValueError as e:
    print(e)  # Saldo insuficiente

12Funções avançadas

lógica
zip, map e filter são funções de alta ordem — recebem outra função como argumento e operam sobre coleções inteiras sem precisar de um loop explícito.
por que usar
código declarativo e expressivo sem loops explícitos desnecessários transformações encadeadas mais legível para operações em coleções
zip — combinar listas
Une dois iteráveis em pares, item por item. Para no menor deles.
nomes = ["Ana", "Bruno", "Carla"]
notas = [8.5, 7.0, 9.2]

for nome, nota in zip(nomes, notas):
    print(f"{nome}: {nota}")
# Ana: 8.5  /  Bruno: 7.0  /  Carla: 9.2

# criar dict direto com zip
ranking = dict(zip(nomes, notas))
map — transformar
Aplica uma função a cada item e devolve um iterável com os resultados.
nums = [1, 2, 3, 4]

dobros = list(map(lambda x: x * 2, nums))
# [2, 4, 6, 8]

nomes = ["ana", "bruno"]
maiusc = list(map(str.upper, nomes))
# ["ANA", "BRUNO"]
filter — filtrar
Mantém apenas os itens para os quais a função retorna True.
nums = [1, 2, 3, 4, 5, 6]

pares = list(filter(lambda x: x % 2 == 0, nums))
# [2, 4, 6]

nomes = ["Ana", "Bruno", "Al"]
longos = list(filter(lambda n: len(n) > 2, nomes))
# ["Ana", "Bruno"]

13Classes (POO básico)

lógica
Uma classe é um molde — define os atributos e comportamentos de todos os objetos desse tipo. __init__ é o construtor: roda automaticamente quando o objeto é criado. self é a referência ao próprio objeto — como dizer "eu" dentro da classe. Cada instância criada tem seus próprios valores, independentes.
por que usar
dados e comportamentos juntos reutilização via instâncias modela conceitos do mundo real escala para sistemas complexos encapsulamento e organização
Python
class Pessoa:
    def __init__(self, nome, idade):
        self.nome  = nome
        self.idade = idade

    def apresentar(self):
        return f"Olá, sou {self.nome} e tenho {self.idade} anos."

# instanciar (criar um objeto)
p = Pessoa("Eduardo", 22)
p.apresentar()
# "Olá, sou Eduardo e tenho 22 anos."

p.nome   # "Eduardo"
p.idade  # 22
herança e métodos especiais
Herança permite que uma classe filha herde atributos e métodos da classe pai. __str__ controla o que print() exibe do objeto. 
class Animal:
    def __init__(self, nome):
        self.nome = nome
    def __str__(self):
        return f"Animal: {self.nome}"

class Cachorro(Animal):
    def latir(self):
        return f"{self.nome} diz: Au!"

c = Cachorro("Rex")
print(c)        # Animal: Rex
c.latir()       # "Rex diz: Au!"

14Padrões úteis

lógica
Pequenos hábitos que tornam o código mais legível, seguro e profissional — sem mudar o que ele faz. Type hints anotam os tipos esperados, docstrings documentam a função, e o operador walrus evita chamadas duplicadas.
por que usar
type hints: erros detectados antes de rodar docstrings: documentação viva via help() walrus: conciso sem sacrificar clareza facilita revisão de código em equipe IDEs oferecem autocomplete mais preciso
type hints
Anotações de tipo — não obrigam nada em runtime, mas documentam e habilitam análise estática de código.
def somar(a: int, b: int) -> int:
    return a + b

def saudar(nome: str) -> str:
    return f"Olá, {nome}!"

# listas tipadas (Python 3.9+)
def media(nums: list[float]) -> float:
    return sum(nums) / len(nums)
docstrings
Strings de documentação — ficam logo abaixo de def ou class e são acessíveis via help().
def calcular_imc(peso: float, altura: float) -> float:
    """Calcula o IMC dado peso (kg) e altura (m)."""
    return peso / altura ** 2

# acessar documentação
help(calcular_imc)
print(calcular_imc.__doc__)
walrus :=
Atribui e retorna o valor na mesma expressão (Python 3.8+). Evita chamar a função duas vezes.
# sem walrus — função chamada duas vezes
if obter_dados():
    processar(obter_dados())

# com walrus — atribui e testa de uma vez
if dados := obter_dados():
    processar(dados)

# útil em while
while linha := arquivo.readline():
    processar(linha)
